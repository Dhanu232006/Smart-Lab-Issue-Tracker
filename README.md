# Smart Lab Issue Tracker

A full-stack web application to monitor and report lab computer issues.

## Tech Stack
- Frontend: React
- Backend: Spring Boot
- Database: MySQL

## Features
- Student issue reporting
- Admin dashboard
- Real-time status tracking

## Future Enhancements
- JWT authentication
